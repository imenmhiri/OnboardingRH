# T-28 — Documentation et vidéo de démonstration

**Couches** : docs · **Agent** : — · **Dépend de** : T-16 à T-26

## Pourquoi

La documentation compte pour 5 % de la note, et la vidéo est le seul moment où le jury voit le
produit fonctionner. Un README écrit la veille se voit.

## Périmètre

- README : installation, architecture, choix techniques, limites connues.
- Note d'architecture : les couches, pourquoi le domaine est pur, comment le multi-sociétés tient.
- Décisions notables et leurs alternatives écartées.
- Vidéo commentée de trois à cinq minutes : une arrivée de bout en bout, un retard escaladé,
  la bascule d'une société à l'autre.

## Hors périmètre

- Documentation utilisateur exhaustive.

## Définition de terminé

- [ ] Un développeur qui découvre le dépôt le fait tourner en suivant le README, sans aide.
- [ ] Les limites connues sont écrites, y compris ce qui n'a pas été vérifié.
- [ ] Vidéo de trois à cinq minutes, commentée, montrant le produit réel.
